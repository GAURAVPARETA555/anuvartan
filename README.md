# ANUVARTAN

## AI-Powered Post-Discharge Care Ecosystem

ANUVARTAN is a healthcare application designed to support patients after hospital discharge by connecting patients, nurses, and doctors through a digital care workflow.

### Features

- Patient, Nurse, and Doctor role-based access
- Post-discharge case monitoring
- Symptom and wound-image reporting
- Nurse review and doctor escalation
- AI-assisted healthcare interaction
- REST API based backend
- JWT authentication
- Mobile application using React Native and Expo
- Django REST Framework backend
- PostgreSQL database

## Technology Stack

### Backend
- Python
- Django
- Django REST Framework
- PostgreSQL
- JWT Authentication

### Mobile
- React Native
- Expo

### AI
- Groq API
- LLM integration

### Deployment
- Render
